# Support

## Setup and product questions

Use a GitHub issue for reproducible setup problems, documentation gaps, or Demo Mode bugs. Search existing issues first and use the provided template.

Include:

- the route or workflow;
- browser, device, Node.js, and npm versions when relevant;
- the smallest reproduction;
- expected and observed behavior;
- fictional screenshots or logs with personal data removed.

## Pilot feedback

Use the founding-tutor pilot issue form for de-identified workflow feedback. Do not include student names, email addresses, lesson records, invitation links, or official test material.

## Account beta

The account beta has no paid support guarantee. Do not use a public issue for account-specific details. Never post an email address, private workspace URL, invitation token, or learner record.

Known limitations, including account recovery and deletion status, are documented in [BUILD_STATE](docs/BUILD_STATE.md).

## Security

For vulnerabilities or suspected credential exposure, stop and follow [SECURITY.md](SECURITY.md). Do not provide exploit details publicly.

## What the project cannot provide

- Official TOEFL support, scores, or score predictions
- Advice from ETS
- Emergency response
- Recovery of browser-local Demo Mode data after site data is cleared
- Permission to use third-party or official assessment content
