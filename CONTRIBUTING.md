# Contributing

TraceTutor is currently validating its founding tutor workflow and commercial
model. Bug reports, accessibility findings, and clearly de-identified product
feedback are welcome.

Outside code contributions are temporarily paused. Please do not submit a pull
request unless a maintainer has first confirmed the scope in an issue.

Never include copyrighted test questions, official passages, learner records,
credentials, or hidden assessment material in an issue or pull request.
