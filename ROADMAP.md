# Roadmap

TraceTutor's roadmap is evidence-led. Dates are intentionally omitted until a change has a maintainer, a tested design, and enough user evidence.

## Now: open-source foundation

- Maintain a reproducible zero-secret Demo Mode
- Keep CI, secret scanning, RLS verification, and production builds green
- Triage public bugs, accessibility findings, and documentation gaps
- Gather de-identified founding-tutor feedback without claiming broad adoption
- Improve contributor onboarding and identify genuinely small first issues

## Next: safe pilot operations

- Add dedicated transactional email and password recovery
- Add a documented self-service account-deletion path
- Regenerate database types from the hosted schema
- Add operational monitoring, backups, and a tested incident runbook
- Validate the tutor workflow with real, permissioned pilot use
- Improve mobile and keyboard workflows from observed feedback
- Define a subject-adapter contract for task types, evidence, diagnosis labels, original content, and evaluation before adding any non-Reading subject

## Later: validated expansion

- Design authenticated offline reconciliation before enabling it
- Add durable distributed AI limits and usage accounting
- Run a separately approved blinded evaluation before enabling live AI for learners
- Evaluate billing only after the price and roster assumptions receive real usage evidence
- Consider additional maintainers after sustained contributions
- Evaluate one evidence-based subject outside TOEFL Reading only after the adapter contract and Reading pilot are verified

## Explicitly out of scope for now

- Official TOEFL score estimates or score predictions
- Copied official questions, passages, or proprietary test-prep material
- Fully automated diagnosis without tutor review
- Advertising trackers or engagement mechanics based only on volume
- Claims of learning efficacy without an appropriate evaluation
- A required paid service for local Demo Mode

## Suggest an item

Open a feature request describing the user problem, affected workflow, evidence, privacy implications, and the smallest useful outcome. Please do not submit learner records or copyrighted assessment content.
